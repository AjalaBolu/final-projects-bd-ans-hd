# Loan Prediction

Predicts whether a loan application will be approved based on applicant financial and demographic data.

## Dataset
Loan dataset sourced from Kaggle (`loan_dataset.csv`).

## Approach
- Data cleaning and preprocessing of applicant features (income, credit history, loan amount, etc.)
- Trained a **Support Vector Machine (SVM)** classifier with a linear kernel

## Results
| Metric | Score |
|---|---|
| Training Accuracy | 77.86% |
| Testing Accuracy | 81.25% |

## Tech Stack
Python, pandas, scikit-learn, matplotlib, seaborn
