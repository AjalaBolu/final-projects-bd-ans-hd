# Machine Learning Projects

A collection of end-to-end machine learning projects covering classification, regression, and deep learning — spanning healthcare diagnostics, NLP, and risk prediction.

## Projects

| Project | Type | Description |
|---|---|---|
| [breast-cancer-prediction](./breast-cancer-prediction) | Classification | Predicts breast cancer diagnosis from tumor features |
| [heart-disease-prediction](./heart-disease-prediction) | Classification | Predicts likelihood of heart disease from patient data |
| [diabetes-prediction](./diabetes-prediction) | Classification | Predicts diabetes risk from health indicators |
| [leukemia-classification](./leukemia-classification) | Deep Learning (CNN) | Classifies white blood cell images into leukemia stages |
| [tuberculosis-prediction](./tuberculosis-prediction) | Classification | Predicts tuberculosis risk/diagnosis |
| [flood-prediction](./flood-prediction) | Classification | Predicts flood risk from environmental data |
| [fake-news-detection](./fake-news-detection) | NLP / Classification | Classifies news articles as real or fake |
| [house-price-prediction](./house-price-prediction) | Regression | Predicts house prices from property features |
| [loan-prediction](./loan-prediction) | Classification | Predicts loan approval likelihood |

More projects will be added over time.

## Tech Stack

Python, scikit-learn, TensorFlow/Keras, pandas, Jupyter Notebook
